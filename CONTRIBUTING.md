# Contributing

This repository is generated from [brainfish-ai/ballet-templates](https://github.com/brainfish-ai/ballet-templates) so all Ballet template collections stay in sync.

- To add or change a template, open a pull request against [brainfish-ai/ballet-templates](https://github.com/brainfish-ai/ballet-templates) following its [contributing guide](https://github.com/brainfish-ai/ballet-templates/blob/main/CONTRIBUTING.md).
- To report a problem with a template here, open an issue in this repository with the template folder name.
